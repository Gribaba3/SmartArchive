# SmartArchive — розумний захищений архіватор

Командний проєкт 2 з дисципліни «Алгоритми і оптимізація програмних рішень», команда **T01**.

Архіватор стискає набір файлів (LZ77 + канонічний Гаффман), шифрує (AES-256-CTR),
захищає цілісність (HMAC-SHA256) і розбиває на томи. Розархіватор відновлює файли побайтово.
Формат описано в [docs/FORMAT_SPEC.md](docs/FORMAT_SPEC.md).

## Запуск з нуля

Потрібен Python 3.10+.

```bash
git clone https://github.com/Gribaba3/SmartArchive.git
cd SmartArchive
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -e ".[dev]"
```

Розпакувати архів (томи можна подавати в будь-якому порядку):

```bash
python -m sarc extract -p algo2026 -o out data/reference/ref_04_seven_groups.arc
python -m sarc extract -p algo2026 -o out data/reference/ref_06_two_volumes.part*.arc
```

Якщо архів пошкоджений, програма не падає: друкує код відмови (`E_MAGIC`, `E_LENGTH`,
`E_HMAC`, `E_PAYLOAD`, `E_CRC`, `E_VOLUME`) і повертає код виходу 2.

Тести, покриття і лінтер (те саме запускає CI):

```bash
pytest --cov=sarc
ruff check .
```

## Структура

| Шлях | Що там | Зона |
|---|---|---|
| `sarc/container.py` | заголовок тому, таблиці файлів і блоків, перевірки | Інтеграція |
| `sarc/crypto.py` | PBKDF2 → K_enc / K_mac, AES-256-CTR, HMAC | Захист |
| `sarc/bitio.py` | бітовий потік MSB-first | Стиснення |
| `sarc/huffman.py` | канонічні коди, декодер | Стиснення |
| `sarc/codec.py` | кодек блоку: токени LZ77 + три дерева | Стиснення / Розбір потоку |
| `sarc/extract.py` | розархіватор, атомарне розпакування | Інтеграція |
| `sarc/cli.py` | командний рядок | Інтеграція |
| `tests/` | тести на еталонних архівах викладача і на примітивах | усі |
| `data/` | матеріали викладача: конфіг, корпус, train/valid, reference | — |
| `docs/FORMAT_SPEC.md` | формат архіву, відновлений з еталонних архівів | — |

Ще не реалізовано: архіватор (побудова дерев Гаффмана, жадібний і лінивий LZ77, рюкзак для томів),
перцептрон, генетичний алгоритм, модуль атаки.
