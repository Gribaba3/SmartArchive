# SmartArchive — розумний захищений архіватор

Командний проєкт 2 з дисципліни «Алгоритми і оптимізація програмних рішень», команда **T01**.

Архіватор стискає набір файлів (LZ77 + канонічний Гаффман), шифрує (AES-256-CTR),
захищає цілісність (HMAC-SHA256) і розбиває на томи. Розархіватор відновлює файли побайтово.
Формат описано в [docs/FORMAT_SPEC.md](docs/FORMAT_SPEC.md).

## Запуск з нуля

Потрібен Python 3.10+.

```bash
git clone https://github.com/Gribaba3/SmartArchive.git
cd SmartArchive
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -e ".[dev]"
```

Створити архів (файли, шаблони або папки):

```bash
python -m sarc archive -o out/corpus.arc data/corpus/
# якщо архів більший за том (64 КБ), буде corpus.part0.arc, corpus.part1.arc, ...
python -m sarc archive -o a.arc file1.txt file2.csv --parser greedy --packer greedy --volume-size 32768
# --packer: dp (ДП за цінністю, за замовчуванням) | dp-weight (класичне ДП за вагою) | greedy
```

Пароль задається змінною середовища `SARC_PASSWORD` або вводиться за запитом.
Прапорець `-p` теж є, але лише для тестів: так пароль потрапляє в історію командного рядка.

```bash
# Linux / macOS
export SARC_PASSWORD=algo2026
# Windows PowerShell:  $env:SARC_PASSWORD = "algo2026"
# Windows cmd:         set SARC_PASSWORD=algo2026

python -m sarc extract -o out data/reference/ref_04_seven_groups.arc
python -m sarc extract -o out "data/reference/ref_06_two_volumes.part*.arc"   # шаблон розгортає програма
python -m sarc extract -o out data/reference/                                  # або всі *.arc у папці
```

Томи можна подавати в будь-якому порядку. Наявні файли в папці не перезаписуються,
поки не додано `--force`.

Якщо архів пошкоджений, програма не падає: друкує код відмови і повертає код виходу 2.

| Код | Коли |
|---|---|
| `E_MAGIC` | не архів SARC або не та версія |
| `E_LENGTH` | том обрізаний або довший, ніж має бути |
| `E_HMAC` | змінено хоч один байт або невірний пароль |
| `E_PAYLOAD` | структурно некоректний вміст, небезпечне ім'я файлу |
| `E_CODE` | некоректна таблиця кодів Гаффмана або недопустиме посилання LZ77 |
| `E_CRC` | контрольна сума відновленого файлу не збіглася |
| `E_VOLUMES` | відсутній / дубльований / чужий том, повтор nonce |
| `E_INPUT` | вхідний файл не знайдено або немає доступу |
| `E_EXISTS` | файл уже є в папці розпакування, а `--force` не задано |
| `E_OUTPUT` | не вдалося записати архів (немає місця, немає прав) |
| `E_MODEL` | не вдалося завантажити модель класифікатора (`sarc/mlp_model.json`) |
| `E_CAPACITY` | розмір тому замалий для таблиці файлів або блоку |

Тести, покриття і лінтер (те саме запускає CI):

```bash
pytest --cov=sarc
ruff check .
```

## Структура

| Шлях | Що там | Зона |
|---|---|---|
| `sarc/container.py` | заголовок тому, таблиці файлів і блоків, перевірки | Інтеграція |
| `sarc/crypto.py` | PBKDF2 → K_enc / K_mac, AES-256-CTR, HMAC | Захист |
| `sarc/bitio.py` | бітовий потік MSB-first | Стиснення |
| `sarc/huffman.py` | побудова кодів (черга з пріоритетами, ліміт 15 біт), канонічні коди, декодер | Стиснення |
| `sarc/codec.py` | кодек блоку: токени LZ77 + три дерева | Стиснення / Розбір потоку |
| `sarc/lz77.py` | хеш-ланцюжки, жадібний і лінивий розбір | Розбір потоку |
| `sarc/packing.py` | рюкзак 0/1: ДП за цінністю і за вагою, жадібний; розкладання по томах | Пакування в томи |
| `sarc/analysis.py` | тип файлу за вмістом (перцептрон), ентропія | Аналіз файлу |
| `sarc/features.py` | 18 ознак файлу з байтів (ентропія, частка друкованих, автокореляція, сигнатури…) | Аналіз файлу |
| `sarc/mlp.py` | перцептрон вручну на numpy: forward, softmax, cross-entropy, backprop; macro-F1 | Аналіз файлу |
| `sarc/mlp_model.json` | навчені ваги перцептрона | Аналіз файлу |
| `sarc/archive.py` | архіватор: блоки, стратегія, томи, шифрування | Інтеграція |
| `experiments/measure.py` | експерименти: Q і таблиці звіту | Інтеграція |
| `experiments/train_mlp.py` | навчання перцептрона, вибір моделі, звіт `docs/MLP_RESULTS.md` | Аналіз файлу |
| `sarc/extract.py` | розархіватор: потоково, атомарно, перевірки томів | Інтеграція |
| `sarc/cli.py` | командний рядок | Інтеграція |
| `tests/` | тести на еталонних архівах викладача і на примітивах | усі |
| `data/` | матеріали викладача: конфіг, корпус, train/valid, reference | — |
| `docs/FORMAT_SPEC.md` | формат архіву, відновлений з еталонних архівів | — |
| `docs/DECISIONS.md` | лог рішень: проблема → варіанти → рішення → чому | усі |

Ще не реалізовано: генетичний алгоритм, модуль атаки, просунуті рівні.

## Класифікатор типу файлу

Тип визначає перцептрон лише за вмістом (розширення ігнорується). Перенавчити:
`python experiments/train_mlp.py` — зберігає `sarc/mlp_model.json` і звіт [docs/MLP_RESULTS.md](docs/MLP_RESULTS.md).
macro-F1 на valid = 1.000 (поріг F1_min = 0.61; випадковий вибір ≈ 0.14).

## Результати

`python experiments/measure.py -o docs/RESULTS.md` — метрика Q і таблиці звіту. Поточні значення:
[docs/RESULTS.md](docs/RESULTS.md). На корпусі: 329 903 → 129 041 Б (коефіцієнт 2.557,
опорний пакувальник викладача — 2.558), Q ≈ 0.80.
